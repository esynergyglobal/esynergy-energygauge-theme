Tools Menu
   

The Tools menu has the following sub menus:

Customize - This menu allows the user to customize the Tool bars.

Options - This option allows the user to change the application user interface layout.  Layout options include Tab location and style.

Settings - This allows the user to set, change or remove the default directory from which input files are initially opened.

Another option in the setting menu is for the feedback control for users when entering building data. This feedback control when set to a particular form of calculation, for example should the user be running Florida 6th Edition 2017 IECC option, the feedback dropdown menu should be set to Florida 6th Edition 2017 IECC option, thus allowing a user to see whether individual data fields fail or pass according to the rules of the feedback standard selected, when entering data in the forms.
