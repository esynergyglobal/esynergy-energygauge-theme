Master Constructs Library Form

The Master Constructs Library is a list of over 300 constructs used in building construction. This serves as a resource from which selected constructs can be inserted into your project.

The user is not allowed to make any changes.

See the section on Working with Grids to add, delete, and modify data.

 

Viewing Selected Materials

You can view selected materials by using the short-list radio buttons provided on the form.

Show All - Clicking this radio button will display all constructs in the library.

Show by Use - Clicking this radio button will allow constructs to be short-listed by general use of the material. After clicking this radio button, you must select the approriate use category from the Combo box below the radio button.

By Conductance - Clicking this radio button will allow short listing by a range of conductance. After clicking this radio button, you must also select the appropriate range from the Combo box below the radio button.

By Heat Capacity - Clicking this radio button will allow short listing by a range of heat capacity. After clicking this radio button, you must also select the appropriate range from the Combo box below the radio button.

By Density - Clicking this radio button will allow short listing by a range of density. After clicking this radio button, you must also select the appropriate range from the Combo box below the radio button.

By Added R-Value - Clicking this radio button will allow short listing by a range of R-Value. After clicking this radio button, you must also select the appropriate range from the Combo box below the radio button.

 

Fields

Use - Specifies the possible use for the construct

Conductance - Specifies the thermal conductivity of the construct

Heat Capacity - Specifies the heat capacity of the construct

Density - Specifies the construct density

Thickness - Specifies the total thickness of the construct

R-Value - Specifies the thermal resistance of the construct

Simple Construct - See explanation under Project Materials and Constructs

No-Mass Construct - See explanation under Project Materials and Constructs

 

Constructs Library Layers Table

The subtable provides the details of the layers in the selected construct. The layers are specified starting from the ouside layer to the inside layer. That is the outermost layer is the first layer.

ID - Specifies the ID of the material the layer is made of. It corresponds to a valid material number from the Master Material Library.

Material - Specifies the name of the material the layer is made of. It corresponds to a valid material name from the Master Material Library.

Thickness - Specifies the thickness of the layer. When a layer is added, the thickness of the material, as specified in the material library, is used. However, an averriding thickness can be entered here, in which case the original thickness in the material library is ignored and the value entered is used.

Framing Factor - Specifies the graming, if any, of the layer. Framing Factor is the ratio of the framing area on the layer to the total area of the layer.

 

The user is not allowed to make any changes.
