Skylight Data Input Form
   

Skylight Info

Data inputs are similar to Window Data Input Form, except shading is not available for skylights.

Has Curb - If checked, indicates that the skylight is a curb mounted skylight.

Material Plastic (Otherwise assumed Glass) - If checked, indicates that the skylight pane is constructed from plastic instead of glass.

ASHRAE 90.1-2010 5.5.4.4.2 Exception - If checked, indicates that the skylight qualifies for the exception outlines in ASHRAE 90.1-2010 5.5.4.4.2 on maximum SGHC for skylights.

Well Factor - Specifies the total fraction of light entering the light well that penetrates to the room below. This is determined by the geometry of the light well and the reflectance of the surfaces in the light well.

Daylighted Area - Specifies the total floor area that is illuminated by daylight from the skylight.

IECC 2012 402.3.3.4 Increased U-factor - If checked, allows the user to use a larger U-factor for the skylight, provided that the skylight is installed above a daylight zone with automatic daylighting controls.

IECC 2012 402.3.3.3 Increased SHGC - If checked, alows the user to use a larger maximum SHGC for the skylight, provided that the skylight is located above daylight zones with automated daylight controls and in the correct climate zone.
