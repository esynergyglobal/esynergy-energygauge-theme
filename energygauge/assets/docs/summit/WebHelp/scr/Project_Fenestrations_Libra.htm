Project Fenestrations Library Form

The Project Fenestration library allows the user to add Fenestrations to the Project, which can then be slected by a project window or skylight as the fenestration type.

\

No. - Specifies the ID number associated with the fenestration

Name - Specifies a name for the fenestration. User can type any convenient, short description

Description - A detailed description that can be up to 50 characters

No. of Panes - Specifies the number of glass panes for the user defined fenestration

Glass Conductance - Specifies the conductance of glass panes for the user defined fenestration

SHGC - Specifies the solar heat gain coefficient of the glass panes for the user defined fenestration

VLT - Specifies the Visible Light Transmittance

Frame Type - Describes the type of frame used

See the section Working with Grids for instructions to add, delete, or modify data.
