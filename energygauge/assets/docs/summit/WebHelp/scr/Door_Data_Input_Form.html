Door Data Input Form
   

Door Info

Data inputs are very similar to the Wall Data Input Form.

Data on placement and location, etc, are not required.

 

Shading - Shading for doors is activated by checking the shading check box. A set of data input cells become visible where shading parameters can be entered.  Enter all data that is applicable.

For a detailed account of shading parameters see the Window Data Input Form.
