Reports Menu
   

Input Report - This produces a detailed report of the project inputs.

Before displaying the input report, the user is asked to select whether the Profiles & Schedules information should be included in the report. The Profiles & Schedules information is voluminous and is not required to be included for Florida Code Compliance but may be mandatory for other compliance calculations.

Note: In certain instances of renovation, addition or shell buildings, only some of the individual reports may be required. For example, if only a system is being replaced, only the system report may be required.  Check your current energy code manual and local jurisdiction for specific requirements.
