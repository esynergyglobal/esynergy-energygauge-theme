View Menu
   

The 'View' menu contains the following sub menus:

Project Explorer - Shows or hides the Project Explorer as applicable.

Status Bar - Displays an informational status bar at the bottom when checked.

DOE Outputs - Has the following sub menus:

* Last Design Run

* Last Run

The calculation engine, DOE-2.1E, produces text outputs that can be viewed for possible errors, warnings and cautions. The above two sub menus are provided only to be used for debugging should the need arise.
