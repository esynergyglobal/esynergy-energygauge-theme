System Data Input Form

 

Acronym - A short description (up to 20 characters)

Description - A detailed description (up to 50 characters)

No. of Units - Enter the number of such units (Use this to input multiple systems serving one or more Zones)

Baseline Cooling Capacity Multiplier, Basline Heating Capacity Multiplier and Baseline Fan Capacity Multiplier - If the unmet hours for the baseline (or reference building) needs adjusting to meet the unmet hour rule, (See ASHRAE 90.1 or 2014 Florida Code for details) these three parameters serve as capacity multipliers for the baseline building to adjust system output. These parameters will not effect the unmet hours for the proposed building, these hours can be met by modifying the capacity of the proposed system itself.

Component Name - The type of the component (whether cooling,heating etc) is displayed. If a check box appears near the name of the component, it indicates that the component is optional and user decided whether to select it or not.

Input Parameter - Shows the different required parameters (like capacity,EER, IPLV etc.) for the respective component.

Options - Describes the option type for the component. Any sub-option may be selected by clicking on the sub option.;

Sub-Option Parameter - If parameter field appears next to a selected sub option, the value of the parameter must be selected.

 

Steps for Entering Data

To select an optional component click on the check box to select it.

Click on the corresponding column. A pop up window will appear (for example: the figure below displays the selection of fan power option). Enter or select the value and then click OK.

To choose a particular option in a component click on the radio button.

Air Distribution System - If checked, compliance for this component will be checked. Required inputs are "Location" and "R-Value".

Energy Recovery Unit - If checked, ERV credit will be applied. Applicable only for the 2010 Florida Code (see the 2010 Florida code for details of credit).
