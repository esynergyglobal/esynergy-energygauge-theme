External Lighting Data Input Form
   

External Light Category - External lighting category. Select one from the list.

Description - You can type your own description or comment here.

No. of Luminaires - Specify the number of light fittings in that space.

Watts per Luminaire - Specify the lighting wattage per fitting.

Luminaire Efficiency - Specify the efficiency of each luminaire.

Area or Length - Input depends on the category selected. Enter length or area. Required units will be shown.

Control Type - Specify the type of control for the luminaire from a drop down list.

 

See the section on Working with Grids to add, delete and modify data.
