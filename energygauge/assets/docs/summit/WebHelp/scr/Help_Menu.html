Help Menu
    

Sub Menus provides access to the Help system.

Local Help - This sub menu opens the contents dialog of the Help system. The user can navigate to any topic from the contents. In addition the user can print any topic displayed or book from the contents dialog.

Online Help - This sub menu take you to the help system posted online with the lastest available changes.

Download pdf Help file  - This sub menu allows you to download and save locally the latest available help file in PDF form.

Technical Support Website - Directs the user to the EnergyGauge Summit technical support website.

Check for Updates  - Checks online if any updates are available.

License ... - Takes you to the License action page, to activate deactivate etc. shown below

About EnergyGauge - Provides information about the installed version of EnergyGauge Summit.

Important Note: Pressing F1 key on your keyboard will provide context sensitive help.
