Steps to Comply with Florida 7th Ed (2020) Building Code
  

Compliance options

The four compliance procedures for the FLORIDA ENERGY CODE COMPLIANCE FOR COMMERCIAL BUILDINGS are:

  1. ASHRAE 90.1-2016 - Energy Cost Budget Method
  2. ASHRAE 90.1-2016 - Envelope Trade-Off Option (Not supported )
  3. ASHRAE 90.1-2016 - Prescriptive Compliance Option
  4. ASHRAE 90.1-2016 - Appendex G Performance Rating Option (Not supported )
  5. IECC 2018 - Total Building Performance Compliance Option
  6. IECC 2018 - Prescriptive Compliance Option
  7. IECC 2018 – Component Performance Alternative Option

These can be invoked by going to the appropriate items in the calculate menu as follows:

'Calculate' -> '7th Edition (2020) Florida Energy Code Compliance'  -> 'IECC 2018 - Total Building Performance Compliance Option' or other options

Steps for compliance:

  1. Open new file and enter data.  The main user manual explains all the screens, input procedures and input details.
  2. After entering inputs go to Calculate -> Error Check.  Correct errors that are found
  3. Run the appropriate compliance Calculate -> 7th Edition (2020) Florida Energy Code Compliance  -> IECC 2018 - Total Building Performance Compliance Option or other options
  4. Check the reports generated to see if the building complies. See section on Appendix A on input and output reports.
  5. Print the reports and look for elements that have failed. The reasons for failing will be given in the reports
  6. Make changes to inputs that have failed and re run the calculations until you are able to comply.
