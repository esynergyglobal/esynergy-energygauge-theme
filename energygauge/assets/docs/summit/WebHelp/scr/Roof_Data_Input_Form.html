Roof Data Input Form
   

Roof Info

Data inputs are very similar to the Wall Data Input Form.

ASHRAE 90.1-2010 5.5.3.1.2 or IECC 2012 402.2.1.1 Exception - If checked, will allow the user to bypass minimum solar reflectance and thermal emittance of the roof. This should only be checked if the user is sure that the roof qualifies for an exception.
