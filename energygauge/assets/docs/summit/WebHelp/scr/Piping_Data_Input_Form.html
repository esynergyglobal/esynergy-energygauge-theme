Piping Data Input Form
   

Type - Specify the Piping application.

Operating Temperature - The operating temperature at which the pipe will operate.

Insulation Conductivity - Specify the conductivity of the insulation around the pipe.

Nominal Pipe Diameter - Specifies the diameter of the pipe.

Insulation Thickness - Specify the thickness of the insulation around the pipe.

Check if Runout up to 4 ft - Specific if the pipe is a runout.

Note: Units are shown on the form.
